
# Simple Interest Calculator

A Bash shell script that calculates simple interest.

## Description
This project calculates simple interest using the principal amount, annual rate of interest, and time period.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Inputs
- Principal amount
- Annual rate of interest (%)
- Time period (years)

## Output
- Calculated simple interest

## How to Run
```bash
bash simple-interest.sh
```
